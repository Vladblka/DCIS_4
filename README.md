# Практическая работа №5: веб-приложение «Учёт музыкальных инструментов»

Веб-приложение на Spring Boot для хранения сведений о музыкальных инструментах.
Вариант: «Музыкальный инструмент».

## Цель работы

Освоить разработку веб-приложения на Spring Boot: обработку HTTP-запросов
контроллерами, формирование HTML-страниц, проверку
введённых пользователем данных и выполнение CRUD-операций с базой данных
PostgreSQL через `JdbcTemplate`.

## Страницы приложения

| Страница | Адрес | Что делает | Пункт меню из работы №4 |
|----------|-------|------------|--------------------------|
| Главная | `/` | Приветствие и ссылки на все разделы | — |
| Таблица записей | `/instruments` | Показывает все записи | 2 — показать все |
| Добавление записи | `/instruments/new` | Форма новой записи, `POST /instruments` | 1 — добавить |
| Изменение записи | `/instruments/edit` → `/instruments/{id}/edit` | Выбор записи, затем форма редактирования, `POST /instruments/{id}` | 3 — изменить по id |
| Удаление записи | `/instruments/delete` → `/instruments/{id}/delete` | Выбор записи, подтверждение, `POST /instruments/{id}/delete` | 4 — удалить по id |
| Поиск по критерию | `/instruments/search?brand=...` | Записи, у которых бренд содержит введённый текст (без учёта регистра) | 5 — поиск по бренду |

## Проверка вводимых данных

Проверки выполняются на сервере при отправке формы; при ошибке форма показывается
снова, введённые значения сохраняются, а под каждым неверным полем выводится
диагностическое сообщение. Дополнительно вверху формы появляется общее сообщение
«Проверьте заполнение полей — ниже указаны ошибки».

| № | Что проверяется | Сообщение |
|---|-----------------|-----------|
| 1 | Текстовые поля (`name`, `brand`, `instrument_type`, `material`) не пустые | «Укажите название инструмента», «Укажите бренд», «Укажите тип инструмента», «Укажите материал» |
| 2 | Длина текста не превышает размер колонки БД | «Название не должно быть длиннее 120 символов» и аналогичные |
| 3 | Цена — число и не отрицательная | «Цена должна быть числом, например 85000.50», «Цена не может быть отрицательной» |
| 4 | У цены не более 10 цифр до запятой и 2 после | «Цена: не более 10 цифр до запятой и 2 после» |
| 5 | Количество — целое число и не отрицательное | «Количество должно быть целым числом, например 3», «Количество не может быть отрицательным» |
| 6 | В поиске заполнено поле бренда | «Введите часть названия бренда для поиска» |


## Описание конфигурации

Приложение построено на Spring Boot, отдельный класс-конфигурация не нужен:
`@SpringBootApplication` включает сканирование компонентов и автонастройку.
Spring сам создаёт следующие бины:

- `DataSource` и `JdbcTemplate` — на основе `spring-boot-starter-jdbc` и параметров из `application.properties`;
- `MusicalInstrumentRepository` — слой доступа к данным (`@Repository`);
- `MusicalInstrumentService` — слой бизнес-логики (`@Service`, `@Transactional`);
- контроллеры `HomeController` и `InstrumentController` — обработка веб-запросов (`@Controller`);
- `SpringTemplateEngine` и `ViewResolver` — рендеринг HTML-шаблонов Thymeleaf.
